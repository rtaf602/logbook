## ติดตั้งครั้งแรก (ทำตามลำดับ)

### ขั้นที่ 1 — แชร์ไฟล์ให้ถึงกัน
1. ไฟล์ **รายชื่อสนามบิน** (บัญชี ohomee.ai.projectwork) → แชร์ → เพิ่ม `ohomee.aviation@gmail.com` สิทธิ์ **ผู้มีสิทธิ์อ่าน (Viewer)**
2. ไฟล์ **ต้นทาง** (บัญชี ohomee.aviation) → แชร์ → เพิ่ม `ohomee.ai.projectwork@gmail.com` สิทธิ์ **Viewer** (สำหรับ IMPORTRANGE ในไฟล์แสดงผล)
3. โฟลเดอร์ **602DB_สำรองรายวัน** ต้องอยู่ในบัญชี ohomee.aviation (หรือแชร์สิทธิ์ Editor ให้บัญชีนี้)

### ขั้นที่ 2 — ติดตั้งสคริปต์ในไฟล์ต้นทาง (ใช้บัญชี ohomee.aviation)
1. เปิดไฟล์ **602DB_LOG BOOK ปีงบ70_ต้นทาง** → เมนู **ส่วนขยาย → Apps Script**
2. ไฟล์ `Code.gs` ที่มีอยู่: ลบของเดิม แล้ววางเนื้อหาจาก `apps-script/Code.gs`
3. กด **＋ → สคริปต์** ตั้งชื่อ `Seed` แล้ววางเนื้อหาจาก `apps-script/Seed.gs`
4. ⚙ **การตั้งค่าโปรเจกต์** → ติ๊ก “แสดงไฟล์ Manifest appsscript.json” → กลับไปหน้าแก้ไข เปิด `appsscript.json` วางเนื้อหาจาก `apps-script/appsscript.json`
5. กด 💾 บันทึก → เลือกฟังก์ชัน **`setup`** ที่แถบด้านบน → **เรียกใช้ (Run)**
   - ครั้งแรกจะขออนุญาต: ตรวจสอบสิทธิ์ → เลือกบัญชี ohomee.aviation → ขั้นสูง → ไปที่โปรเจกต์ → อนุญาต
   - เสร็จแล้วในไฟล์ต้นทางจะมีชีท 2–6 พร้อมข้อมูลปัจจุบัน และมีตัวตั้งเวลาสำรองทุกคืน
   - เรียก `setup` ซ้ำได้ ไม่ทำให้ข้อมูลซ้ำ (ใส่ข้อมูลตั้งต้นเฉพาะตอนชีทยังว่าง)

### ขั้นที่ 3 — เปิดเป็น Web app
1. ในหน้า Apps Script กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. ⚙ เลือกประเภท **เว็บแอป (Web app)**
   - ดำเนินการในฐานะ (Execute as): **ฉัน (ohomee.aviation@gmail.com)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
3. กด **Deploy** → คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
4. ทดสอบ: เปิด URL นั้นในเบราว์เซอร์ ต้องเห็น `{"ok":true,"service":"602 LOG BOOK",...}`

> “ทุกคน” หมายถึงเรียก Web app ได้โดยไม่ต้องล็อกอิน Google แต่ทุกคำขอต้องมีรหัสเข้าใช้งานที่ถูกต้อง และการลบ / แก้ชั่วโมงจัดสรร / แก้รายการตัวเลือก ต้องมีรหัส ADMIN — เซิร์ฟเวอร์ตรวจเองทุกครั้ง

### ขั้นที่ 4 — ใส่ลิงก์ในเว็บ แล้วเปิด GitHub Pages
1. แก้ `config.js` ใน repo นี้: เปลี่ยน `PASTE_WEB_APP_URL_HERE` เป็น URL จากขั้นที่ 3 แล้ว commit
2. GitHub → repo `rtaf602/logbook` → **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save
3. รอ 1–2 นาที เว็บจะอยู่ที่ **https://rtaf602.github.io/logbook/**

### ขั้นที่ 5 — เปิดไฟล์แสดงผล
ไฟล์ **602DB_LOG BOOK ปีงบ70_แสดงผล** มีแท็บ 2–5 ที่ใส่สูตร IMPORTRANGE ไว้แล้ว
- เปิดแต่ละแท็บ → คลิกช่อง **A1** ที่ขึ้น `#REF!` → กด **อนุญาตการเข้าถึง (Allow access)** (ครั้งเดียว)

## ใช้งานประจำวัน
- เจ้าหน้าที่: เปิดเว็บ → ใส่รหัสเข้าใช้งาน → บันทึกภารกิจ (ดูคู่มือการใช้งาน)
- หน้าเว็บดึงข้อมูลใหม่ทุก 30 วินาที และทันทีหลังบันทึก / แก้ / ลบ
- ทุกการแก้ไขและลบถูกบันทึกในชีท **2 ประวัติแก้ไข-ลบ** (การลบเก็บข้อมูลทั้งรายการไว้กู้คืน)
- **ห้ามแก้ชีท 2–5 ในไฟล์ต้นทางด้วยมือ** — แก้ผ่านหน้าเว็บเท่านั้น

## แก้โค้ดสคริปต์ภายหลัง
แก้ `Code.gs` แล้ว **Deploy → จัดการการทำให้ใช้งานได้ (Manage deployments) → ✏ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่ → Deploy**
(ทำแบบนี้ URL เดิมใช้ต่อได้ ไม่ต้องแก้ `config.js`)

## เปลี่ยนรหัส
- เซิร์ฟเวอร์: Apps Script → ⚙ การตั้งค่าโปรเจกต์ → **Script Properties** → เพิ่ม `ENTRY_HASH` / `ADMIN_HASH` = ค่า SHA-256 (ตัวพิมพ์เล็ก) ของรหัสใหม่
- หน้าเว็บ: แก้ค่า `GATE_HASH` (รหัสเข้าใช้งาน) และ `DEL_HASH` (รหัส ADMIN) ใน `index.html` ให้ตรงกัน
- หาค่า SHA-256 ได้จากคอนโซลเบราว์เซอร์:
  `crypto.subtle.digest("SHA-256", new TextEncoder().encode("รหัสใหม่")).then(b=>console.log([...new Uint8Array(b)].map(x=>x.toString(16).padStart(2,"0")).join("")))`

## ขึ้นปีงบใหม่ (เช่น ปีงบ 71)
1. สร้างไฟล์ `602DB_LOG BOOK ปีงบ71_ต้นทาง` (บัญชี ohomee.aviation) → ติดตั้งสคริปต์เหมือนขั้นที่ 2–3
   แต่ใน `Code.gs` แก้ `FY: 2571` และ `SHEET_ID` เป็นรหัสไฟล์ใหม่ · ใน `Seed.gs` ล้าง `entries` เป็น `[]` และใส่ชั่วโมงจัดสรรปีใหม่ใน `alloc`
2. เพิ่มบรรทัด `2571: "URL ใหม่"` ใน `config.js` (ปีเก่าเก็บไว้ ดูย้อนหลังได้)
3. สร้างไฟล์แสดงผลปีใหม่ แล้วเปลี่ยนรหัสไฟล์ในสูตร IMPORTRANGE
